# Reoteab 1.0 Beta 2

This Tester build focuses on long-session reliability and clearer diagnostics.

## Tester improvements

- Added optional Roblox working-set trimming for long macro sessions
- Added concise build and session diagnostics for route, playback, reconnect, and failsafe settings
- Improved tester build identity across the UI, runtime logs, and webhook footers
- Preserved Macro Report, fishing climb timing, and WebView stability work from Beta 1
