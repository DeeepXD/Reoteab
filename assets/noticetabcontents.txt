# Reoteab v0.1.4

Reoteab is an unofficial community-maintained continuation based on Coteab v2.2.0.

## Stability

- Added WebView memory monitoring and safe maintenance during unattended sessions
- Recreated WebView2 renderer resources without restarting the macro or backend workers
- Switched to a bounded frontend-pulled UI event queue so presentation work cannot block the macro

## Fixes and reliability

- Fixed a first-launch stall caused by clearing old WebView profile folders before the window opened
- Improved biome transition, screenshot, and webhook worker isolation during UI failures
- Preserved the current Sol's RNG paths, presets, auto-calibration, and webhook improvements
