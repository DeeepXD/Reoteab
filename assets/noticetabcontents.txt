# Reoteab v0.1.3

Reoteab is an unofficial community-maintained continuation based on Coteab v2.2.0.

## Improvements

- Updated VIP and non-VIP fishing and Captain Flarg routes for the current Sol's RNG map
- Added macro presets with optional images, plus fishing indicator auto-calibration
- Added appearance customization for merchant and aura webhook embeds

## Fixes and reliability

- Fixed repeated merchant alerts and duplicate/stale webhook work after macro restarts
- Bounded runtime log history to support longer sessions
- Runtime files now use Reoteab AppData while preserving compatible Coteab config imports
