# Reoteab v1.0.0

Reoteab 1.0 is the stable release of the tested 1.0 improvements.

## Highlights

- Improved VIP and Non-VIP fishing routes, including the Non-VIP post-climb turn
- Playback-multiplier-aware fishing movement and existing recovery/failsafe handling
- Macro Report, WebView stability safeguards, and optional Roblox memory trimming

## Notes

- Reoteab uses its bundled interface for this release so an old AppData UI cannot override it.
- Roblox updates, display scaling, and calibration can still affect automation. Recalibrate when your setup changes.
