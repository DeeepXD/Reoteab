# Reoteab v1.0.0 Stable is here

Reoteab 1.0 has officially graduated from beta.

## What's included

- Verified VIP and Non-VIP fishing-path improvements, including the Non-VIP post-climb correction.
- Playback-multiplier-aware movement, fishing recovery, and selling-route coverage.
- Macro Report, WebView stability safeguards, and optional Roblox memory trimming.
- Existing reconnect, merchant, webhook, and configuration compatibility improvements from the 1.0 beta series.

## Update

Download `Reoteab.exe` from the official release, replace your older executable, and keep your existing AppData settings, presets, and calibration files.

https://github.com/DeeepXD/Reoteab/releases/tag/v1.0.0

As always, recalibrate if your resolution, display scaling, or Roblox UI changes.
